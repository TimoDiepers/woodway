# Atlas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An interactive web map (`atlas/`) that shows every per-place result of the talk's model on the native 0.5° grid, with a time slider, a per-cell chain panel and a global strip, in English (default) and German.

**Architecture:** A Python exporter writes compact binary fields plus a JSON meta file from `nbs`; the browser decodes them into typed arrays and evaluates the model's per-year values exactly (ΔT from two per-cell factors and 18 forest-type curves, DAC net share by linear interpolation between LCA base years, as the model itself does). A painter turns the active layer into a Mercator-resampled RGBA image that MapLibre shows as an image source on globe or flat map.

**Tech Stack:** Python 3.11 + numpy (exporter, pytest); Vite 5, React 18, TypeScript 5, Tailwind 3, MapLibre GL 5 via react-map-gl 8, Zustand 5, Radix/shadcn primitives, Recharts 2, Vitest 2 + jsdom.

**Spec:** `docs/superpowers/specs/2026-10-10-atlas-design.md`

## Global Constraints

- Every number on screen comes from the model export; no invented values, no "illustrative" data. Each layer shows its source line.
- One tree rule as in the talk: typical forest of the cell (`nbs.landscape.assign_species()`), planted in `T_START` (2026), SSP2-4.5, years `nbs.constants.YEARS` (2026–2100). The spec's "2026–2150" for the tree slider is superseded by the model's horizon `T_END = 2100`; use 2026–2100 everywhere.
- Palettes, units and category colours are the deck's: `nbs.map_fields.SCALES` and `CATEGORIES`, exported into `meta.json`, never retyped in TypeScript.
- Cells without the quantity are grey land with a named reason ("no room for trees", "too cold for sorbent DAC"), never a low value; ocean stays transparent.
- English and German, English default; `en.ts` and `de.ts` have identical keys. Place names keep the country code: "Aachen (DE)", "Joensuu (FI)", "Marabá (BR)".
- Static site, no backend, no telemetry. Fonts are local (copied from `deck/assets/vendor/fonts`).
- Mobile (390 px wide) must fully work.
- The map, legend, slider and cell panel accept their state as props so a later React deck can embed them; the Zustand store is only one owner.
- All data under 6 MB gzipped.
- The woodway repo (`~/Documents/Coding/woodway`) is only read from, never modified.
- Commits: no Co-Authored-By line, no "Generated with Claude Code" line (user rule).

2. Longitudes at exactly ±180° and latitudes beyond ±85° (Mercator limit) must map to a valid cell or to "no cell", not to an index out of range. → Task 6 (`lookup.test.ts` "edges").

- Produces `meta.json` with this exact shape (later tasks read it):

```jsonc
{
  "version": 1,
  "grid": {"nlat": 360, "nlon": 720, "d": 0.5, "lat0": 90.0, "lon0": -180.0},
  "years": [2026, ..., 2100],
  "fields": {"<name>": {"offset": 0, "dtype": "f4" | "u1", "length": 259200}},
  "types": ["dbf_boreal", ...],              // 18 keys; field "type" stores index+1, 0 = none
  "typeGroup": {"dbf_boreal": "dbf", ...},    // key → Hasler category key
  "curves": {"<type>": {"m": [...], "phiCo2": [...], "phiAlbUnit": [...], "dtCo2": [...], "dtAlbUnit": [...]}},
  "dacYears": [2020, 2030, 2040, 2050, 2075, 2100],   // fields "dacNet2020" ... "dacNet2100"
  "build": {"years": [...], "countries": [...], "cells": [[i, j], ...], "owner": [...], "capacityGt": [[...per year] per country]},
  "global": {"years": [...], "need": [...], "afterTrees": [...], "afterDac": [...], "dacCapacityGt": [...],
             "paths": {"alle": [...], "kuehlt": [...], "forst": [...]}, "areasGha": {"alle": 0.828, "kuehlt": 0.393}},
  "sites": [{"name": "Aachen (DE)", "lat": 50.78, "lon": 6.08, "color": "#2f6fb7"}, ...],
  "scales": { ...nbs.map_fields.SCALES... },
  "categories": {"waldtyp": [ ...nbs.map_fields.CATEGORIES["waldtyp"]... ]},
  "colors": {"land": "#ddd6c7", "tooCold": "#bdb5a5"},
  "reference": [{"i": 0, "j": 0, "dt2050": 0.0, "dt2100": 0.0, "net2100": 0.0, "dac2026": 0.0, "dac2045": 0.0}]
}
```

- Fields (all length 360·720, row-major, row 0 = northernmost, column 0 = 180° W):
  `land` u1 (1 where land: finite CRU temperature or reforestable area), `type` u1, `area` f4 (reforestable m², 0 outside), `trees` f4 (area / 5 m²), `sun` f4 (W/m²), `darker` f4 (pp), `light` f4 (W per tree), `a` f4 (CO₂ factor), `b` f4 (albedo product), `elec` f4 (MWh/t, NaN where too cold), `dacOk` u1, `dacNet<YYYY>` f4 (share 0–1, NaN where too cold).
- Units in curves: `m` kg C per tree at the reference site, `phiCo2` and `phiAlbUnit` W/m², `dtCo2` K per tree, `dtAlbUnit` K per unit product. Per cell: m = a·m_ref, φ_CO₂ = a·phiCo2, φ_α = b·phiAlbUnit, ΔT = a·dtCo2 + b·dtAlbUnit.

`tests/test_atlas_export.py`:

```python
"""The atlas export reproduces the model it was cut from."""
import json
from pathlib import Path

import numpy as np
import pytest

ROOT = Path(__file__).resolve().parents[1]
DATA = ROOT / "atlas" / "public" / "data"


def _load():
    meta = json.loads((DATA / "meta.json").read_text(encoding="utf-8"))
    raw = (DATA / "fields.bin").read_bytes()
    out = {}
    for name, f in meta["fields"].items():
        dt = np.float32 if f["dtype"] == "f4" else np.uint8
        out[name] = np.frombuffer(raw, dtype=dt, count=f["length"], offset=f["offset"]).reshape(360, 720)
    return meta, out


def _dt(meta, fields, year):
    k = meta["years"].index(year)
    dt = np.full((360, 720), np.nan)
    for n, key in enumerate(meta["types"], start=1):
        m = fields["type"] == n
        c = meta["curves"][key]
        dt[m] = fields["a"][m] * c["dtCo2"][k] + fields["b"][m] * c["dtAlbUnit"][k]
    return dt


def test_files_exist_and_are_small():
    meta, fields = _load()
    assert meta["version"] == 1
    assert len(meta["types"]) == 18
    assert meta["years"][0] == 2026 and meta["years"][-1] == 2100
    size = (DATA / "fields.bin").stat().st_size + (DATA / "meta.json").stat().st_size
    assert size < 40e6  # raw; gzipped well under 6 MB (checked in Task 11)


def test_cooling_area_is_the_talks_039_gha():
    meta, fields = _load()
    dt = _dt(meta, fields, 2100)
    cool = fields["area"][(fields["type"] > 0) & (dt < 0)].sum() / 1e13
    assert cool == pytest.approx(meta["global"]["areasGha"]["kuehlt"], abs=0.005)
    assert cool == pytest.approx(0.393, abs=0.005)


def test_dac_median_2026_is_46_percent():
    meta, fields = _load()
    y0, y1 = 2020, 2030
    w = (2026 - y0) / (y1 - y0)
    eta = (1 - w) * fields["dacNet2020"] + w * fields["dacNet2030"]
    assert float(np.nanmedian(eta)) == pytest.approx(0.4647, abs=0.002)


def test_reference_cells_are_consistent():
    meta, fields = _load()
    dt50, dt100 = _dt(meta, fields, 2050), _dt(meta, fields, 2100)
    for r in meta["reference"]:
        assert dt50[r["i"], r["j"]] == pytest.approx(r["dt2050"], rel=1e-5)
        assert dt100[r["i"], r["j"]] == pytest.approx(r["dt2100"], rel=1e-5)


@pytest.mark.slow
def test_dt_2100_equals_the_model_everywhere():
    from nbs.dac_compare import tree_efficiency_grid
    from nbs.map_fields import _tree_dt_grid
    from nbs.constants import T_START

    meta, fields = _load()
    dt = _dt(meta, fields, 2100)
    ref = _tree_dt_grid()
    ok = np.isfinite(ref)
    np.testing.assert_allclose(dt[ok], ref[ok], rtol=1e-5)
    eff = tree_efficiency_grid(T_START)
    k = meta["years"].index(2100)
    carbon = np.zeros_like(dt)
    for n, key in enumerate(meta["types"], start=1):
        m = fields["type"] == n
        carbon[m] = fields["a"][m] * meta["curves"][key]["dtCo2"][k]
    np.testing.assert_allclose((dt / carbon)[ok], eff[ok], rtol=1e-5)


@pytest.mark.slow
def test_dac_net_equals_the_model_between_base_years():
    from nbs.dac import efficiency_grid

    meta, fields = _load()
    for year, (y0, y1) in [(2045, (2040, 2050)), (2060, (2050, 2075))]:
        w = (year - y0) / (y1 - y0)
        eta = (1 - w) * fields[f"dacNet{y0}"].astype(float) + w * fields[f"dacNet{y1}"].astype(float)
        ref = efficiency_grid(year)
        ok = np.isfinite(ref)
        np.testing.assert_allclose(eta[ok], ref[ok], rtol=1e-5, atol=1e-6)
```

`atlas/export_atlas.py`:

```python
"""Data for the atlas (atlas/public/data): every per-place result of the model on the 0.5 deg grid.

Writes meta.json (grid, curves, palettes, global paths, reference values) and fields.bin (360x720
fields, float32 or uint8, offsets in meta.json). The browser evaluates years exactly:
  tree:  dT(t) = a * dtCo2_type(t) + b * dtAlbUnit_type(t)   (nbs.aggregate: site factor and albedo
         product scale the two unit curves linearly)
  DAC:   net share interpolated linearly between the LCA base years (nbs.dac._interp does the same).

    uv run python atlas/export_atlas.py
"""
from __future__ import annotations

import json
from pathlib import Path

import numpy as np

from nbs.aggregate import _product_no_nan, co2_factor_grid
from nbs.animations import _STAND_AREA_M2, SITES, _by_type, typical_alpha_q_product
from nbs.constants import A_EARTH_M2, T_START, TAU_ATM, YEARS
from nbs.dac import dac_possible, efficiency_grid, energy_grid, lca_vintages
from nbs.dac_climate import climate_grid
from nbs.forest_data import reforestable_area_m2
from nbs.landscape import assign_species
from nbs.map_fields import CATEGORIES, LAND, SCALES, TOO_COLD
from nbs.pipeline import run_single_tree
from nbs import albedo_grid
from nbs.response import convolve_response, green_temperature
from nbs.species import SPECIES, get_species, reference_site

ROOT = Path(__file__).resolve().parents[1]
OUT = ROOT / "atlas" / "public" / "data"
CHART_DATA = ROOT / "deck" / "chart_data"


def _r(a, nd=6):
    return [float(f"{v:.{nd}g}") for v in np.asarray(a, dtype=float)]


def type_curves() -> dict:
    """Per forest type, the curves of one tree at its reference site, planted in T_START."""
    g_t = green_temperature("ssp245")
    out = {}
    for key in SPECIES:
        res = run_single_tree(key, lat_deg=reference_site(key), plant_year=T_START)
        sp = get_species(key)
        unit_alb = -TAU_ATM * np.asarray(res.trajectory.closure, dtype=float) * sp.stand_area_m2 / A_EARTH_M2
        out[key] = {
            "m": _r(res.trajectory.stock_kgC),
            "phiCo2": _r(res.phi_co2),
            "phiAlbUnit": _r(unit_alb),
            "dtCo2": _r(convolve_response(g_t, res.phi_co2)),
            "dtAlbUnit": _r(convolve_response(g_t, unit_alb)),
        }
    return out


class _Fields:
    def __init__(self):
        self.parts: list[bytes] = []
        self.meta: dict = {}
        self.offset = 0

    def add(self, name: str, arr: np.ndarray, dtype: str) -> None:
        assert arr.shape == (360, 720), (name, arr.shape)
        a = np.ascontiguousarray(arr, dtype=np.float32 if dtype == "f4" else np.uint8)
        b = a.tobytes()
        pad = (-self.offset) % 4  # keep every float32 field 4-byte aligned for Float32Array views
        if pad:
            self.parts.append(b"\0" * pad)
            self.offset += pad
        self.meta[name] = {"offset": self.offset, "dtype": dtype, "length": a.size}
        self.parts.append(b)
        self.offset += len(b)


def build_table() -> dict:
    """DAC capacity per cell over time: the optimisation behind the deck's DAC film."""
    film = json.loads((CHART_DATA / "dacfilm.json").read_text(encoding="utf-8"))
    cells = [[int(round((90.0 - lat) / 0.5 - 0.5)), int(round((lon + 180.0) / 0.5 - 0.5))] for lon, lat in film["cells"]]
    return {"years": film["years"], "countries": film["countries"], "cells": cells, "owner": film["owner"],
            "capacityGt": film["paths"]["opt"]["cc"]}


def global_paths() -> dict:
    z = json.loads((CHART_DATA / "zeitpfade.json").read_text(encoding="utf-8"))
    film = json.loads((CHART_DATA / "dacfilm.json").read_text(encoding="utf-8"))
    return {"years": z["jahre"], "need": z["noetig"], "afterTrees": z["baeume_rest"],
            "afterDac": film["paths"]["opt"]["dac"], "dacCapacityGt": film["paths"]["opt"]["tot"],
            "paths": {k: z["pfade"][k] for k in ("alle", "kuehlt", "forst")},
            "areasGha": {k: z["flaechen_gha"][k] for k in ("alle", "kuehlt")}}


def main() -> None:
    OUT.mkdir(parents=True, exist_ok=True)
    keys = list(SPECIES)
    species = assign_species()
    code = np.zeros((360, 720), dtype=np.uint8)
    a = np.full((360, 720), np.nan)
    b = np.full((360, 720), np.nan)
    for n, key in enumerate(keys, start=1):
        m = species == key
        code[m] = n
        a[m] = co2_factor_grid(key)[m]
        b[m] = _product_no_nan(key)[m]

    area = np.where(code > 0, reforestable_area_m2(), 0.0)
    land = np.isfinite(climate_grid()["t_mean_c"]) | (area > 0)
    ok = dac_possible()
    base_years = sorted(int(y) for y in lca_vintages()["jahre"])

    f = _Fields()
    f.add("land", land.astype(np.uint8), "u1")
    f.add("type", code, "u1")
    f.add("area", area, "f4")
    f.add("trees", area / _STAND_AREA_M2, "f4")
    f.add("sun", _by_type(albedo_grid.insolation_grid), "f4")
    f.add("darker", -100.0 * _by_type(albedo_grid.delta_alpha_grid), "f4")
    f.add("light", -typical_alpha_q_product() * _STAND_AREA_M2, "f4")
    f.add("a", a, "f4")
    f.add("b", b, "f4")
    f.add("elec", np.where(ok, energy_grid("waermepumpe")["strom"], np.nan), "f4")
    f.add("dacOk", ok.astype(np.uint8), "u1")
    for y in base_years:
        f.add(f"dacNet{y}", efficiency_grid(y), "f4")

    curves = type_curves()
    years = [int(y) for y in YEARS]

    def dt_at(i, j, year):
        k = years.index(year)
        c = curves[keys[code[i, j] - 1]]
        return float(np.float32(a[i, j]) * c["dtCo2"][k] + np.float32(b[i, j]) * c["dtAlbUnit"][k])

    reference = []
    for s in SITES:
        i, j = int((90.0 - s.lat) // 0.5), int((s.lon + 180.0) // 0.5)
        if code[i, j] == 0:
            continue
        k = years.index(2100)
        carbon = np.float32(a[i, j]) * curves[keys[code[i, j] - 1]]["dtCo2"][k]
        reference.append({"i": i, "j": j, "dt2050": dt_at(i, j, 2050), "dt2100": dt_at(i, j, 2100),
                          "net2100": dt_at(i, j, 2100) / carbon,
                          "dac2026": float(efficiency_grid(2026)[i, j]), "dac2045": float(efficiency_grid(2045)[i, j])})

    meta = {
        "version": 1,
        "grid": {"nlat": 360, "nlon": 720, "d": 0.5, "lat0": 90.0, "lon0": -180.0},
        "years": years,
        "fields": f.meta,
        "types": keys,
        "typeGroup": {k: k.split("_")[0] for k in keys},
        "curves": curves,
        "dacYears": base_years,
        "build": build_table(),
        "global": global_paths(),
        "sites": [{"name": f"{s.name} ({s.country})", "lat": s.lat, "lon": s.lon, "color": s.color} for s in SITES],
        "scales": SCALES,
        "categories": {"waldtyp": CATEGORIES["waldtyp"]},
        "colors": {"land": LAND, "tooCold": TOO_COLD},
        "reference": reference,
    }
    (OUT / "fields.bin").write_bytes(b"".join(f.parts))
    (OUT / "meta.json").write_text(json.dumps(meta, ensure_ascii=False, separators=(",", ":"), allow_nan=False),
                                   encoding="utf-8")
    print(f"wrote {OUT}: {f.offset / 1e6:.1f} MB fields, {len(reference)} reference cells")


if __name__ == "__main__":
    main()
```

```ts
import { en } from "./en";
import { de } from "./de";
import { useAtlas } from "@/store";

export type Key = keyof typeof en;
export type Lang = "en" | "de";
const DICT: Record<Lang, Record<Key, string>> = { en, de };

export function translate(lang: Lang, key: Key, vars?: Record<string, string | number>): string {
  let s = DICT[lang][key] ?? en[key];
  if (vars) for (const [k, v] of Object.entries(vars)) s = s.replaceAll(`{${k}}`, String(v));
  return s;
}

export function useT() {
  const lang = useAtlas((s) => s.lang);
  return (key: Key, vars?: Record<string, string | number>) => translate(lang, key, vars);
}

/** Numbers in the language's style: 1,234.5 / 1.234,5. */
export function useNum() {
  const lang = useAtlas((s) => s.lang);
  return (v: number, digits = 0) =>
    v.toLocaleString(lang === "de" ? "de-DE" : "en-GB", { minimumFractionDigits: digits, maximumFractionDigits: digits });
}
```

```ts
import type { Atlas, Meta } from "./types";

export class LoadError extends Error {
  constructor(public file: string, detail: string) {
    super(`${file}: ${detail}`);
  }
}

async function get(fetcher: typeof fetch, base: string, file: string): Promise<Response> {
  let res: Response;
  try {
    res = await fetcher(base + file);
  } catch (e) {
    throw new LoadError(file, String(e));
  }
  if (!res.ok) throw new LoadError(file, `HTTP ${res.status}`);
  return res;
}

export async function loadAtlas(base = "data/", fetcher: typeof fetch = fetch): Promise<Atlas> {
  const [metaRes, binRes] = await Promise.all([get(fetcher, base, "meta.json"), get(fetcher, base, "fields.bin")]);
  const meta = (await metaRes.json()) as Meta;
  const buf = await binRes.arrayBuffer();
  const f: Atlas["f"] = {};
  for (const [name, d] of Object.entries(meta.fields)) {
    f[name] = d.dtype === "f4" ? new Float32Array(buf, d.offset, d.length) : new Uint8Array(buf, d.offset, d.length);
  }
  const buildByCell = new Map<number, number>();
  meta.build.cells.forEach(([i, j], k) => buildByCell.set(i * meta.grid.nlon + j, k));
  return { meta, f, buildByCell };
}
```

```ts
export const NLON = 720;

export const cellIJ = (cell: number): [number, number] => [Math.floor(cell / NLON), cell % NLON];

export function typeKey(at: Atlas, cell: number): string | null {
  const n = at.f.type[cell];
  return n ? at.meta.types[n - 1] : null;
}

export function yearIndex(at: Atlas, year: number): number {
  const y = at.meta.years;
  return Math.max(0, Math.min(y.length - 1, Math.round(year) - y[0]));
}

export function deltaT(at: Atlas, cell: number, year: number): number {
  const key = typeKey(at, cell);
  if (!key) return NaN;
  const c = at.meta.curves[key], k = yearIndex(at, year);
  return at.f.a[cell] * c.dtCo2[k] + at.f.b[cell] * c.dtAlbUnit[k];
}

export function netShare(at: Atlas, cell: number, year: number): number {
  const key = typeKey(at, cell);
  if (!key) return NaN;
  const c = at.meta.curves[key], k = yearIndex(at, year);
  const carbon = at.f.a[cell] * c.dtCo2[k];
  return carbon === 0 ? NaN : (carbon + at.f.b[cell] * c.dtAlbUnit[k]) / carbon;
}

/** Linear between the LCA base years, as nbs.dac._interp; the slider never leaves 2026–2100. */
export function dacNet(at: Atlas, cell: number, year: number): number {
  if (!at.f.dacOk[cell]) return NaN;
  const ys = at.meta.dacYears;
  const y = Math.max(at.meta.years[0], Math.min(at.meta.years.at(-1)!, year));
  let k = 0;
  while (k < ys.length - 2 && y > ys[k + 1]) k++;
  const w = (y - ys[k]) / (ys[k + 1] - ys[k]);
  return (1 - w) * at.f[`dacNet${ys[k]}`][cell] + w * at.f[`dacNet${ys[k + 1]}`][cell];
}

export function dacBuildMt(at: Atlas, cell: number, year: number): number {
  const k = at.buildByCell.get(cell);
  if (k === undefined) return 0;
  const b = at.meta.build, owner = b.owner[k];
  const t = Math.max(0, Math.min(b.years.length - 1, Math.round(year) - b.years[0]));
  const nCells = b.owner.filter((o) => o === owner).length;
  return (1000 * b.capacityGt[owner][t]) / nCells;
}

export function coolsFrom(at: Atlas, cell: number): number | null {
  for (const y of at.meta.years) if (deltaT(at, cell, y) < 0) return y;
  return null;
}

export interface CellSeries { years: number[]; m: number[]; phiCo2: number[]; phiAlb: number[]; dt: number[] }

  const key = typeKey(at, cell);
  if (!key) return null;
  const c = at.meta.curves[key], a = at.f.a[cell], b = at.f.b[cell];
  return {
    years: at.meta.years,
    m: c.m.map((v) => a * v),
    phiCo2: c.phiCo2.map((v) => a * v),
    phiAlb: c.phiAlbUnit.map((v) => b * v),
    dt: c.dtCo2.map((v, k) => a * v + b * c.dtAlbUnit[k]),
  };
}
```

```ts
import type { Scale } from "@/data/types";

export type RGBA = [number, number, number, number];

export function hexToRgba(hex: string, alpha = 255): RGBA {
  return [parseInt(hex.slice(1, 3), 16), parseInt(hex.slice(3, 5), 16), parseInt(hex.slice(5, 7), 16), alpha];
}

export function scaleT(sc: Scale, v: number): number {
  const [lo, hi] = sc.domain;
  let t: number;
  if (sc.mid !== undefined) {
    t = v <= sc.mid ? 0.5 * (v - lo) / (sc.mid - lo) : 0.5 + 0.5 * (v - sc.mid) / (hi - sc.mid);
  } else {
    t = (v - lo) / (hi - lo);
  }
  t = Math.max(0, Math.min(1, t));
  return sc.gamma ? Math.pow(t, sc.gamma) : t;
}

const cache = new WeakMap<Scale, RGBA[]>();

export function scaleColor(sc: Scale, v: number): RGBA {
  let stops = cache.get(sc);
  if (!stops) { stops = sc.stops.map((s) => hexToRgba(s)); cache.set(sc, stops); }
  const x = scaleT(sc, v) * (stops.length - 1);
  const k = Math.min(stops.length - 2, Math.floor(x)), f = x - k;
  const p = stops[k], q = stops[k + 1];
  return [0, 1, 2].map((c) => Math.round(p[c] + (q[c] - p[c]) * f)).concat(255) as RGBA;
}
```

```ts
export const LAT_MAX = 85;

export function cellAt(lon: number, lat: number): number | null {
  if (!Number.isFinite(lon) || !Number.isFinite(lat) || Math.abs(lat) > 90 || Math.abs(lon) > 180) return null;
  const i = Math.min(359, Math.floor((90 - lat) / 0.5));
  const j = Math.min(719, Math.floor((lon + 180) / 0.5));
  return i * 720 + j;
}

export function cellCenter(cell: number): { lon: number; lat: number } {
  const i = Math.floor(cell / 720), j = cell % 720;
  return { lon: -180 + 0.5 * j + 0.25, lat: 90 - 0.5 * i - 0.25 };
}
```

```ts
import type { Atlas } from "@/data/types";
import type { Layer } from "@/model/layers";
import { scaleOf } from "@/model/layers";
import { hexToRgba, scaleColor, type RGBA } from "@/color/scale";
import { LAT_MAX } from "./lookup";

export const IMG_W = 1440, IMG_H = 1440;
export const IMAGE_COORDS: [[number, number], [number, number], [number, number], [number, number]] =
  [[-180, LAT_MAX], [180, LAT_MAX], [180, -LAT_MAX], [-180, -LAT_MAX]];

const pack = ([r, g, b, a]: RGBA) => ((a << 24) | (b << 16) | (g << 8) | r) >>> 0;

export function cellColors(at: Atlas, layer: Layer, year: number, out = new Uint32Array(360 * 720)): Uint32Array {
  const sc = scaleOf(at, layer);
  const land = pack(hexToRgba(at.meta.colors.land));
  const cold = pack(hexToRgba(at.meta.colors.tooCold));
  const cats = at.meta.categories.waldtyp.map((c) => pack(hexToRgba(c.color)));
  for (let c = 0; c < out.length; c++) {
    if (!at.f.land[c]) { out[c] = 0; continue; }
    const v = layer.value(at, c, year);
    if (layer.kind === "cat") out[c] = v >= 0 ? cats[v] : land;
    else if (Number.isFinite(v) && sc) out[c] = pack(scaleColor(sc, v));
    else out[c] = layer.reason(at, c) === "reason.tooCold" ? cold : land;
  }
  return out;
}

const ROW_OF: Int32Array = (() => {
  const rows = new Int32Array(IMG_H);
  const yMax = Math.log(Math.tan(Math.PI / 4 + (LAT_MAX * Math.PI) / 360));
  for (let r = 0; r < IMG_H; r++) {
    const y = yMax - ((r + 0.5) / IMG_H) * 2 * yMax;
    const lat = (Math.atan(Math.sinh(y)) * 180) / Math.PI;
    rows[r] = Math.min(359, Math.floor((90 - lat) / 0.5));
  }
  return rows;
})();

export function mercatorImage(colors: Uint32Array, out = new Uint32Array(IMG_W * IMG_H)): Uint32Array {
  for (let r = 0; r < IMG_H; r++) {
    const src = ROW_OF[r] * 720, dst = r * IMG_W;
    for (let x = 0; x < IMG_W; x++) out[dst + x] = colors[src + ((x * 720) / IMG_W) | 0];
  }
  return out;
}
```

```tsx
import Map, { Layer as MLayer, Marker, Source, type MapRef, type MapLayerMouseEvent } from "react-map-gl/maplibre";
import type { ImageSource } from "maplibre-gl";
import "maplibre-gl/dist/maplibre-gl.css";
import type { Atlas } from "@/data/types";
import type { Layer } from "@/model/layers";
import { paperBasemap, paperBasemapDark } from "@/lib/mapStyle";
import { cellColors, mercatorImage, IMAGE_COORDS, IMG_W, IMG_H } from "./paint";
import { cellAt, cellCenter } from "./lookup";
import Borders from "./Borders";

export interface AtlasMapProps {
  atlas: Atlas; layer: Layer; year: number; cell: number | null;
  onCell(cell: number | null): void;
  onHover?(cell: number | null, x: number, y: number): void;
  projection?: "globe" | "mercator"; dark?: boolean;
  sites?: { name: string; lat: number; lon: number; color: string }[];
  initialView?: { longitude: number; latitude: number; zoom: number };
}

const EMPTY = "data:image/gif;base64,R0lGODlhAQABAAAAACw=";

export default function AtlasMap({ atlas, layer, year, cell, onCell, onHover, projection = "globe", dark = false,
  sites = [], initialView = { longitude: 10, latitude: 25, zoom: 1.6 } }: AtlasMapProps) {
  const mapRef = useRef<MapRef | null>(null);
  const canvas = useMemo(() => { const c = document.createElement("canvas"); c.width = IMG_W; c.height = IMG_H; return c; }, []);
  const buffers = useMemo(() => ({ colors: new Uint32Array(360 * 720), img: new Uint32Array(IMG_W * IMG_H) }), []);
  const [loaded, setLoaded] = useState(false);
  const urlRef = useRef<string | null>(null);
  const pending = useRef(0);

  // Repaint on layer/year change: one paint per animation frame, the latest request wins.
  useEffect(() => {
    if (!loaded) return;
    const ticket = ++pending.current;
    const raf = requestAnimationFrame(() => {
      if (ticket !== pending.current) return;
      cellColors(atlas, layer, year, buffers.colors);
      mercatorImage(buffers.colors, buffers.img);
      const ctx = canvas.getContext("2d")!;
      ctx.putImageData(new ImageData(new Uint8ClampedArray(buffers.img.buffer), IMG_W, IMG_H), 0, 0);
      canvas.toBlob((blob) => {
        if (!blob || ticket !== pending.current) return;
        const url = URL.createObjectURL(blob);
        const src = mapRef.current?.getMap().getSource("atlas") as ImageSource | undefined;
        src?.updateImage({ url, coordinates: IMAGE_COORDS });
        if (urlRef.current) URL.revokeObjectURL(urlRef.current);
        urlRef.current = url;
      });
    });
    return () => cancelAnimationFrame(raf);
  }, [atlas, layer, year, loaded, canvas, buffers]);

  const pick = (e: MapLayerMouseEvent) => {
    const c = cellAt(e.lngLat.lng, e.lngLat.lat);
    return c !== null && atlas.f.land[c] ? c : null;
  };

  const sel = cell !== null ? cellCenter(cell) : null;
  return (
    <Map
      ref={mapRef}
      initialViewState={initialView}
      mapStyle={dark ? paperBasemapDark : paperBasemap}
      projection={projection}
      onLoad={() => setLoaded(true)}
      onClick={(e) => onCell(pick(e))}
      onMouseMove={onHover ? (e) => onHover(pick(e), e.point.x, e.point.y) : undefined}
      onMouseLeave={onHover ? () => onHover(null, 0, 0) : undefined}
      style={{ position: "absolute", inset: 0 }}
      attributionControl={{ compact: true }}
    >
      <Source id="atlas" type="image" url={EMPTY} coordinates={IMAGE_COORDS}>
        <MLayer id="atlas-layer" type="raster" paint={{ "raster-resampling": "nearest", "raster-opacity": 0.95, "raster-fade-duration": 0 }} />
      </Source>
      <Borders dark={dark} />
      {sites.map((s) => (
        <Marker key={s.name} longitude={s.lon} latitude={s.lat} anchor="center">
          <span className="block h-3 w-3 rounded-full border-2 border-white" style={{ background: s.color }} title={s.name} />
        </Marker>
      ))}
      {sel && (
        <Marker longitude={sel.lon} latitude={sel.lat} anchor="center">
          <span className="block h-4 w-4 rounded-sm border-2 border-ink" aria-hidden />
        </Marker>
      )}
    </Map>
  );
}
```

```tsx
import { useEffect, useRef } from "react";
import { Pause, Play } from "lucide-react";
import { useT } from "@/i18n/useT";

const YEARS_PER_SECOND = 6;

export function TimeSlider({ year, onYear, playing, onPlaying, min = 2026, max = 2100 }:
  { year: number; onYear(y: number): void; playing: boolean; onPlaying(p: boolean): void; min?: number; max?: number }) {
  const t = useT();
  const yearRef = useRef(year);
  yearRef.current = year;
  useEffect(() => {
    if (!playing) return;
    let last = performance.now(), acc = yearRef.current >= max ? min : yearRef.current, raf = 0;
    const tick = (now: number) => {
      acc += ((now - last) / 1000) * YEARS_PER_SECOND; last = now;
      if (acc >= max) { onYear(max); onPlaying(false); return; }
      onYear(acc); raf = requestAnimationFrame(tick);
    };
    raf = requestAnimationFrame(tick);
    return () => cancelAnimationFrame(raf);
  }, [playing, min, max, onYear, onPlaying]);
  return (
    <div className="flex items-center gap-3">
      <button aria-label={t(playing ? "slider.pause" : "slider.play")} onClick={() => onPlaying(!playing)}
        className="grid h-9 w-9 place-items-center rounded-full bg-accent text-paper">
        {playing ? <Pause size={16} /> : <Play size={16} />}
      </button>
      <input type="range" role="slider" aria-label={t("slider.year")} min={min} max={max} step={1} value={Math.round(year)}
        onChange={(e) => { onPlaying(false); onYear(+e.target.value); }} className="w-full accent-[rgb(var(--color-accent))]" />
      <output className="w-12 text-right font-serif text-lg tabular-nums">{Math.round(year)}</output>
    </div>
  );
```

```tsx
function Chart({ title, years, series, year }: { title: string; years: number[]; series: { key: string; color: string; values: number[] }[]; year: number }) {
  const data = years.map((y, k) => Object.fromEntries([["year", y], ...series.map((s) => [s.key, s.values[k]])]));
  return (
    <section className="mt-3">
      <h3 className="text-xs font-medium text-inkMuted">{title}</h3>
      <div className="h-28">
        <ResponsiveContainer width="100%" height="100%">
          <LineChart data={data} margin={{ top: 6, right: 8, bottom: 0, left: -18 }}>
            <XAxis dataKey="year" type="number" domain={[years[0], years.at(-1)!]} ticks={[2026, 2050, 2075, 2100]} tick={{ fontSize: 11 }} />
            <YAxis tick={{ fontSize: 11 }} width={44} />
            <ReferenceLine y={0} stroke="currentColor" strokeOpacity={0.3} />
            <ReferenceLine x={year} stroke="currentColor" strokeDasharray="3 3" />
            <Tooltip formatter={(v: number) => v.toFixed(1)} labelFormatter={(y) => String(y)} />
            {series.map((s) => <Line key={s.key} dataKey={s.key} name={s.key} stroke={s.color} dot={false} strokeWidth={2} isAnimationActive={false} />)}
          </LineChart>
        </ResponsiveContainer>
      </div>
    </section>
  );
}

export function CellPanel({ atlas, cell, year, onClose }: { atlas: Atlas; cell: number; year: number; onClose(): void }) {
  const t = useT(), num = useNum();
  const { lat, lon } = cellCenter(cell);
  const key = typeKey(atlas, cell);
  const s = cellSeries(atlas, cell);
  const cool = key ? coolsFrom(atlas, cell) : null;
  const eta = dacNet(atlas, cell, year);
  const build = dacBuildMt(atlas, cell, year);
  const [group, zone] = key ? key.split("_") : ["", ""];
  return (
    <article className="relative text-sm">
      <button aria-label={t("panel.close")} onClick={onClose} className="absolute right-0 top-0 grid h-8 w-8 place-items-center rounded hover:bg-ink/5"><X size={16} /></button>
      <p className="text-xs text-inkMuted">{t("panel.cell", { lat: num(lat, 2), lon: num(lon, 2) })}</p>
      {key && s ? (
        <>
          <h2 className="mt-1 font-serif text-lg font-semibold">{t("panel.forest", { type: t(`type.${group}` as Key), zone: t(`zone.${zone}` as Key) })}</h2>
          <p className="text-inkMuted">{t("panel.area", { area: num(atlas.f.area[cell] / 1e6), trees: num(atlas.f.trees[cell] / 1e6, 1) })}</p>
          <p className="mt-2 font-medium">{cool ? t("panel.coolsFrom", { year: cool }) : t("panel.neverCools")}</p>
          <Chart title={t("panel.stock")} years={s.years} year={year} series={[{ key: "m", color: "#3f8a55", values: s.m }]} />
          <Chart title={t("panel.forcing")} years={s.years} year={year} series={[
            { key: t("panel.forcingCo2"), color: "#2f7d4f", values: s.phiCo2.map((v) => v * 1e15) },
            { key: t("panel.forcingAlb"), color: "#d0632a", values: s.phiAlb.map((v) => v * 1e15) }]} />
          <Chart title={t("panel.temperature")} years={s.years} year={year} series={[{ key: "ΔT", color: "#14532d", values: s.dt.map((v) => v * 1e15) }]} />
        </>
      ) : (
        <p className="mt-2">{t("panel.noForest")}</p>
      )}
      <h3 className="mt-4 font-serif text-base font-semibold">{t("panel.dac")}</h3>
      {atlas.f.dacOk[cell] ? (
        <ul className="text-inkMuted">
          <li>{t("panel.dacElec", { mwh: num(atlas.f.elec[cell], 2) })}</li>
          <li>{t("panel.dacNet", { pct: num(eta * 100), year: Math.round(year) })}</li>
          {build > 0 && <li>{t("panel.dacBuild", { mt: num(build, 1), year: Math.round(year) })}</li>}
        </ul>
      ) : (
        <p className="text-inkMuted">{t("panel.dacTooCold")}</p>
      )}
    </article>
  );
}
```
