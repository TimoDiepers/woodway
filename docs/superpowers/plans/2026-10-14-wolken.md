**Goal:** Add the low-cloud brightening over forest (Duveiller et al. 2021) as a third tree effect to the model and to the talk, with every deck number recomputed.

**Architecture:** A new module `nbs.cloud_grid` turns Duveiller's monthly Δ cloud fraction into a brightening product Δα_W·q̇_ein [W/m²] on the same 1° → 0.5° grid and tiers as `nbs.albedo_grid`. A thin `nbs.light` adds it to the albedo product; every consumer that today reads `alpha_q_product` reads `light_product` instead, so FaIR runs, maps and aggregation pick the clouds up without further change. `NBS_CLOUDS=0` switches the clouds off everywhere (regression and backup numbers).

**Tech Stack:** Python 3.11, numpy, xarray, uv, pytest; deck in HTML/KaTeX/ECharts (`deck/build.py`); `pyreadr` only as a one-off `uv run --with` in the prepare script.

**Spec:** `docs/superpowers/specs/2026-10-14-wolken-design.md`

## Global Constraints

- Δα_W(Monat) = Δf(Monat) · r_W · d with `R_CLOUD = 0.5` (Cerasoli f_C) and `D_AFTERNOON = 0.5`; fixed before any result, never tuned afterwards.
- Product with the insolation month by month, then annual mean; forcing like the albedo: `−(P_α + P_W) · τ_atm · f · A_Baum / A_Erde`, τ_atm = 0.854 unchanged.
- Sign convention: `alpha_q_product` < 0 = darker (warming); `cloud_q_product` > 0 = more cloud (cooling); `light_product = alpha_q_product + cloud_q_product`.
- Types: ENF, EBF → EFO; DNF, DBF → DFO; MF → mean of EFO and DFO where both exist, else whichever exists.
- Gaps: local → median of the 10° latitude band per month and type → 0 (no cloud signal known). Negative Δf stays.
- `NBS_CLOUDS=0` must reproduce today's numbers bit for bit.
- Deck: German slide text, notation rules (one-letter base symbols, word indices), country codes on slides, numbers only from `fakten.json`, planting year named, "Wolken" never a slogan in titles.
- Commits without Co-Authored-By and without "Generated with Claude Code" (user rule).
- Design changes to slides are shown as screenshots and approved before they are committed.

## Review Focus

- A cell with forest-type data for only one of EFO/DFO under `mixed` → must use the existing one, not NaN (test in Task 2).
- A species whose latitude band has no Duveiller cloud cell at all (southern boreal bins) → product 0, tier 2, never NaN (test in Task 2).
- Snow-season negative Δf (Joensuu, March) → negative cloud product, not clipped to zero (test in Task 2).
- `NBS_CLOUDS=0` in a fresh process → `light_product` identical to `alpha_q_product` (test in Task 3).
- Lat orientation of the prepared file vs. the Duveiller 2018 native grid (north-to-south) → the Aachen cell carries Aachen's values (test in Task 1 and 2).

```python
"""Bin Duveiller et al. (2021) cloud-change data onto the 1-degree Duveiller (2018) grid.

Input: data/raw/duveiller2021_data_for_figures.zip (Zenodo 10.5281/zenodo.4727774,
CC-BY-4.0), files df_dCFC_MOD05_{EFO,DFO}.Rdata: monthly absolute change of
low cloud fractional cover (MODIS Aqua 13:30, Cloud CCI 2004-2014) for a full
transition herbaceous -> forest, 0.35-degree cells, already filtered by the
authors (uncertainty <= 0.1, cover fraction >= 0.2, 0.5/99.5 % quantiles;
code/harvest/harvest___get-S4T-results-in-df.R).

Output: data/clouds/duveiller2021_dcfc_1deg.npz -- mean of the 0.35-degree
values inside each 1-degree cell, lat north to south like alb_det.nc.

    uv run --with pyreadr python scripts/prepare_clouds.py
"""

from __future__ import annotations

import tempfile
import zipfile
from pathlib import Path

import numpy as np
import pyreadr

ROOT = Path(__file__).resolve().parents[1]
SRC = ROOT / "data" / "raw" / "duveiller2021_data_for_figures.zip"
OUT = ROOT / "data" / "clouds" / "duveiller2021_dcfc_1deg.npz"
MONTHS = ["Jan", "Feb", "Mar", "Apr", "May", "Jun", "Jul", "Aug", "Sep", "Oct", "Nov", "Dec"]
LAT = np.arange(89.5, -90.0, -1.0)
LON = np.arange(-179.5, 180.0, 1.0)


def _bin(df) -> np.ndarray:
    tot = np.zeros((12, 180, 360))
    cnt = np.zeros((12, 180, 360))
    m = df["month"].astype(str).map(MONTHS.index).to_numpy()
    i = np.clip((89.999 - df["lat"].to_numpy()).astype(int), 0, 179)
    j = np.clip((df["lon"].to_numpy() + 180.0).astype(int), 0, 359)
    np.add.at(tot, (m, i, j), df["dCFC"].to_numpy())
    np.add.at(cnt, (m, i, j), 1.0)
    with np.errstate(invalid="ignore"):
        return np.where(cnt > 0, tot / cnt, np.nan).astype(np.float32)


def main() -> None:
    out = {"lat": LAT, "lon": LON}
    with tempfile.TemporaryDirectory() as tmp, zipfile.ZipFile(SRC) as z:
        for t in ("EFO", "DFO"):
            name = f"data_for_figures/df_dCFC_MOD05_{t}.Rdata"
            path = z.extract(name, tmp)
            out[t] = _bin(next(iter(pyreadr.read_r(path).values())))
    OUT.parent.mkdir(parents=True, exist_ok=True)
    np.savez_compressed(OUT, **out)
    print(f"geschrieben: {OUT}")


if __name__ == "__main__":
    main()
```

```python
@lru_cache(maxsize=None)
def _monthly_insolation_native_cached(species_key: str) -> NDArray:
    lat = _native_lat_for(species_key, "grassland")
    parts = []
    for b in _OPEN_PARTS:
        a = _load_monthly("albedo", species_key, b, True)
        s = _load_monthly("swr", species_key, b, True)
        parts.append(None if a is None or s is None else _quotient_with_zonal_fill(a, s, lat))
    q = _combine_open(parts)
    if q is None:
        _, qsw = _fallback_row_values()
        return np.repeat(np.repeat(qsw[::2][:, None], 360, axis=1)[None], 12, axis=0)
    # the quotient exists only in co-occurrence cells; every other cell gets its
    # 10-degree band's median of the same month (insolation is set by latitude)
    out = q.copy()
    edges = np.arange(-90.0, 90.0 + ZONAL_BIN_WIDTH_DEG, ZONAL_BIN_WIDTH_DEG)
    band = np.clip(np.digitize(lat, edges) - 1, 0, len(edges) - 2)
    for bi in np.unique(band):
        rows = np.where(band == bi)[0]
        for m in range(12):
            block = q[m, rows, :]
            ok = np.isfinite(block)
            if ok.any():
                fill = out[m, rows, :]
                fill[~ok] = float(np.median(block[ok]))
                out[m, rows, :] = fill
    return out


def monthly_insolation_native(species_key: str) -> NDArray:
    """(12, 180, 360) surface insolation [W/m^2] on the native 1-degree grid,
    open-land baseline, local quotient where measured, else the month's
    10-degree band median. Used by nbs.cloud_grid."""
    return _monthly_insolation_native_cached(species_key).copy()
```

```python
"""Low-cloud brightening over forest, from Duveiller et al. (2021).

Forests make more boundary-layer cumulus than the grass or cropland they
replace (Duveiller, G. et al. 2021, Nat. Commun. 12, 4337): monthly absolute
change of cloud fraction Delta_f for a full transition herbaceous -> forest.
Converted to a brightening after Cerasoli et al. (2021, PNAS 118,
e2026241118): a cloud raises reflectance by R_CLOUD, and the cumulus stands
for the afternoon share D_AFTERNOON of the daylight:

    Delta_alpha_W = Delta_f * R_CLOUD * D_AFTERNOON

multiplied with the surface insolation month by month like the albedo
product. Sign: positive = brighter = cooling, the opposite of
alpha_q_product's darker-is-negative convention, so the two simply add
(nbs.light.light_product).

Gaps (data only where forest and open land lie side by side) are filled per
month from the median of the same type's cells in the 10-degree latitude
band; a band with no cell at all gets 0 -- no cloud signal known there.
Only local, low, shortwave effects: advection blurs the signal (likely an
underestimate), longwave is neglected.
"""

from __future__ import annotations

from functools import lru_cache
from pathlib import Path

import numpy as np
from numpy.typing import NDArray

from nbs.albedo_grid import ZONAL_BIN_WIDTH_DEG, _interpolate_missing_months, _regrid, monthly_insolation_native
from nbs.constants import D_AFTERNOON, R_CLOUD
from nbs.species import get_species

DATA = Path(__file__).resolve().parents[2] / "data" / "clouds" / "duveiller2021_dcfc_1deg.npz"
_TYPES: dict[str, tuple[str, ...]] = {
    "evergreen_needleleaf": ("EFO",),
    "evergreen_broadleaf": ("EFO",),
    "deciduous_needleleaf": ("DFO",),
    "deciduous_broadleaf": ("DFO",),
    "mixed": ("EFO", "DFO"),
}
_TIER_LOCAL, _TIER_ZONAL, _TIER_NONE = 0, 1, 2


@lru_cache(maxsize=1)
def _data() -> dict[str, NDArray]:
    d = np.load(DATA)
    return {k: d[k].astype(float) for k in ("lat", "lon", "EFO", "DFO")}


def delta_cloud_native(species_key: str) -> NDArray:
    """(12, 180, 360) Delta_f for the species' forest type, NaN without retrieval."""
    d = _data()
    stack = np.stack([d[t] for t in _TYPES[get_species(species_key).igbp_class]])
    with np.errstate(invalid="ignore"), np.testing.suppress_warnings() as sup:
        sup.filter(RuntimeWarning)
        return np.nanmean(stack, axis=0)


@lru_cache(maxsize=None)
def _monthly_native_tiered(species_key: str) -> tuple[NDArray, NDArray]:
    raw = delta_cloud_native(species_key) * R_CLOUD * D_AFTERNOON * monthly_insolation_native(species_key)
    raw = _interpolate_missing_months(raw)
    local = np.isfinite(raw).all(axis=0)
    out = np.where(np.isfinite(raw), raw, np.nan)
    tier = np.where(local, _TIER_LOCAL, _TIER_NONE).astype(np.int8)
    lat = _data()["lat"]
    edges = np.arange(-90.0, 90.0 + ZONAL_BIN_WIDTH_DEG, ZONAL_BIN_WIDTH_DEG)
    band = np.clip(np.digitize(lat, edges) - 1, 0, len(edges) - 2)
    for bi in np.unique(band):
        rows = np.where(band == bi)[0]
        loc = local[rows, :]
        if not loc.any():
            continue
        for m in range(12):
            block = out[m, rows, :]
            block[~loc] = float(np.median(raw[m, rows, :][loc]))
            out[m, rows, :] = block
        t = tier[rows, :]
        t[~loc] = _TIER_ZONAL
        tier[rows, :] = t
    return np.nan_to_num(out, nan=0.0), tier


@lru_cache(maxsize=None)
def _grid_cached(species_key: str) -> tuple[NDArray, NDArray]:
    native, tier = _monthly_native_tiered(species_key)
    return np.stack([_regrid(native[m]) for m in range(12)]), _regrid(tier)


def monthly_cloud_product(species_key: str) -> NDArray:
    """(12, 360, 720) W/m^2: Delta_alpha_W * q_in per month, positive = brighter."""
    return _grid_cached(species_key)[0].copy()


def cloud_q_product(species_key: str) -> NDArray:
    """(360, 720) W/m^2: annual mean of monthly_cloud_product."""
    return _grid_cached(species_key)[0].mean(axis=0)


def cloud_provenance_grid(species_key: str) -> NDArray:
    """(360, 720) int8: 0 lokal, 1 zonal (band median), 2 keine (set to 0)."""
    return _grid_cached(species_key)[1].copy()
```

Replace the `np.testing.suppress_warnings` construction with `warnings.catch_warnings(); warnings.simplefilter("ignore", RuntimeWarning)` if numpy version lacks it. `_regrid` must accept int8 (it duplicates cells); cast with `.astype(np.int8)` after if it returns float.

```python
"""Net extra light per forest: darker canopy (albedo) plus more low clouds.

light_product = alpha_q_product + cloud_q_product [W/m^2]; negative means the
forest makes the Earth absorb more light (warming). Every forcing, map and
aggregate reads this, so the cloud effect enters the whole model in one place.
NBS_CLOUDS=0 in the environment switches the clouds off (today's numbers,
backup "ohne Wolken").
"""

from __future__ import annotations

import os

from numpy.typing import NDArray

from nbs.albedo_grid import alpha_q_product, monthly_product
from nbs.cloud_grid import cloud_q_product, monthly_cloud_product


def clouds_enabled() -> bool:
    return os.environ.get("NBS_CLOUDS", "1") != "0"


def light_product(species_key: str, *, clouds: bool | None = None) -> NDArray:
    p = alpha_q_product(species_key)
    return p + cloud_q_product(species_key) if (clouds_enabled() if clouds is None else clouds) else p


def monthly_light_product(species_key: str, *, clouds: bool | None = None) -> NDArray:
    p = monthly_product(species_key)
    return p + monthly_cloud_product(species_key) if (clouds_enabled() if clouds is None else clouds) else p
```
