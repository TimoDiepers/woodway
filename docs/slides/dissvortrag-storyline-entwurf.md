## Leitidee: Systemgrenze als Treppe

Ein Kapitel = eine Systemgrenze. Jedes Kapitel endet mit dem Ergebnis, das das nächste als Eingang braucht.

```
1 Baum        Massenbilanz um einen Baum      → liefert m(t), ṁ(t), Δα(t)
2 Klima       Energiebilanz um den Planeten   → liefert ΔT(t) eines Baums, t*
3 Fläche      vom Baum zur Karte              → liefert Potenzial in GtC und K
4 Einordnung  Aufforstung neben Alternativen  → liefert die Antwort auf Folie 4
```

Aus 3 Kapiteln werden 4. Nichts wird gelöscht, drei Folien wandern, eine wird gestrichen, zwei werden zusammengelegt.
